# ip-subnet-calculator-college-mini_project
IP Subnetting calculator in python

Nothing fancy: run the Python script and go from there.

This is the first thing I ever automated. It started as a maths sum from
college (subnetting), and I turned it into a Python script instead of
working it out by hand every time. Writing it is what got me hooked on
coding and on automating any repetitive task that can be automated.


## What it does
Run the .py file, enter an IP address and a subnet mask, and it shows:
- Network address
- Broadcast address
- Usable host range and number of hosts
- Wildcard mask

It can also pick a random IP from the subnet, 

How to run:  python "python IP subnetting.py"
